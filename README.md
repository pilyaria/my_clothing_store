# Личный гардероб

Небольшой сайт домашней распродажи одежды и техники. В каталоге собраны вещи с фотографиями, размерами, состоянием и ценами; готовые образы показывают, как вещи сочетаются друг с другом.

## Возможности

- Каталог одежды с поиском и фильтрами по категориям.
- Отдельные разделы техники, аксессуаров и парфюмерии с косметикой.
- Страницы товаров с галереей фотографий и увеличением снимков.
- Подборки готовых образов со списком входящих в них вещей.
- Адаптивный интерфейс для компьютеров и мобильных устройств.

Это витрина личной распродажи, а не интернет-магазин: корзины, оформления заказа и регистрации нет.

## Запуск

Проект не требует установки зависимостей или сборки. Откройте `index.html` в браузере или запустите локальный сервер из корневой папки проекта:

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Содержимое проекта

- `index.html` — разметка сайта, каталог товаров и готовых образов, а также клиентская логика.
- `css/style.css` — стили и адаптивная раскладка.
- `img/` — фотографии товаров и образов.

Чтобы изменить каталог, отредактируйте массивы `products`, `techProducts`, `accessoryProducts`, `beautyProducts` и `looks` в `index.html`. Фотографии добавляйте в `img/` и указывайте их имена в данных соответствующих товаров или образов.
